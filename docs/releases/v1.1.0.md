## Unsaved work is never lost

Until now, unsaved tabs were written to disk only when the window was closed normally.
A crash, a forced shutdown, Windows restarting for updates, or Android stopping the app in
the background lost everything typed since the start. Opening a file from the file manager
started a second window, and whichever window closed last overwrote the other's tabs.

- **Every unsaved buffer has its own draft file**, written a moment after you stop
  typing, when the window loses focus, and on exit. Untitled tabs and unsaved changes to
  files both come back on the next start, however the last run ended.
- **Unsaved changes to a file that has since been deleted** come back as an untitled
  document instead of disappearing.
- **One window per user.** Opening a file while Inkdown is running opens it as a tab in
  that window. *New Window* still opens a separate window.
- A tab you close on purpose (after saving, or with *Don't Save*) stays closed.

The setting `"hot_exit": false` turns this off.

## Notes

Untitled tabs are where notes start. Now they can be filed.

- **File in Notes** (menu *Notes*, or the command palette) saves the current draft as a
  Markdown file in your Notes folder, named after its first line, in the notebook you
  pick. A file that is already saved is moved there instead.
- **File All Drafts in Inbox** files every unsaved draft in one step.
- **Notebooks** are folders inside the Notes folder: create them from the picker or with
  *New Notebook*, and move a note between them with *File in Notes*.
- **Browse Notes** opens the Notes folder in the sidebar, where notes can be renamed,
  deleted and searched like any other folder.

The Notes folder is `Documents/Inkdown Notes` unless `"notes_folder"` in the settings
names another place. On Android it is inside the app's own documents.

## A phone interface

On a phone Inkdown no longer looks like a small desktop window.

- A title bar with the document name; tap it to switch between open documents.
- **Read, Write and Markdown along the bottom edge**, where a thumb reaches them.
- **A formatting strip above the keyboard** while editing: undo, redo, bold, headings,
  lists, links, paste and more, scrollable sideways.
- **Bottom sheets with large rows** replace the cascading menus: New, Open, Save, Share
  and export, Notes, Find, Tools, Settings, Help.
- Larger touch targets throughout.

Tablets and wide windows keep the desktop layout.

## Editor

- **Find understands look-around and back-references.** Patterns such as `(?<=\$)\d+`
  and `\b(\w+) \1\b` now work in Find, Replace and Find in Files, with `$1` in the
  replacement. Ordinary patterns still run on the fast engine.
- *About Inkdown* shows frame timings (build, paint, frames per second), to help track
  down slow scrolling on a particular device.

## Known limits

- Android scrolling could again only be checked on an emulator that is itself slow. If
  it is not smooth on your phone, scroll a document, open *Help > About Inkdown*, and
  report the three frame figures shown there.
- A second window opened with *New Window* keeps its own drafts safe, but its tabs are
  not part of the session that is restored.
- The rest is unchanged from [1.0.2](v1.0.2.md).

## Testing for this release
