Inkdown 1.0.1 adds an updater and a Help menu, fixes commands on read-only documents, and
publishes the project under the GNU General Public License, version 3 or later.

## Downloads

| Platform | File | Status |
| --- | --- | --- |
| Windows 10 / 11 x64, installer | `Inkdown-Setup.exe` | Stable |
| Windows x64, portable | `inkdown-windows-x64.exe` | Stable |
| Android 8+ (arm64, x86_64) | `inkdown-android.apk` | Beta |
| macOS 11+ universal | `Inkdown-macos-universal.dmg` | Preview |
| Linux x86_64 | `inkdown-linux-x86_64.tar.gz` | Preview |

`SHA256SUMS.txt` lists the checksum of every file. The Windows installer is not
code-signed yet (SmartScreen: *More info > Run anyway*); the macOS app is not notarised
(right-click > *Open* the first time).

**Coming from 1.0.0:** that version has no updater, so install 1.0.1 by running the new
`Inkdown-Setup.exe` once. Later versions will offer themselves.

## New

- **Updates.** Inkdown looks for a newer release once a day and tells you when there is
  one. *Help > Check for Updates* (also in *About*) checks on demand.
  - On Windows, the installed copy downloads the installer, verifies its SHA-256 against
    the published checksum, then closes, updates and opens again with the same documents.
  - The portable exe and the macOS and Linux builds open the download page instead.
  - The check is one plain request to GitHub. Nothing about you or your documents is
    sent. Turn it off with `"check_for_updates": false` in *Preferences > Settings*.
- **Help menu**: Welcome Tour, Keyboard Shortcuts, Documentation, Release Notes, Report
  an Issue, Check for Updates, About.
- **Licence.** Inkdown is free software under GPL-3.0-or-later: you can use, change and
  share it, and anything distributed from it must stay open under the same licence.
  There is now a contributing guide, code of conduct, security policy and issue
  templates.

## Fixed

- With a read-only document active (an image, a binary file or an Avro data file),
  commands such as closing the tab or changing mode from the palette did nothing.
- *Tools: Avro Records to a JSON Document* and *Avro Schema to a Document* now work.
  They did nothing in 1.0.0 because of the bug above.
- A silent install can now replace a running copy when asked to (`--relaunch`).

## Known limits

Unchanged from 1.0.0: see the [1.0.0 notes](v1.0.0.md). In addition:

- The updater verifies the download against the checksum published with the release.
  Because the installer is not code-signed, this guards against a damaged download, not
  against a compromised release.
- The in-place update was tested against a local stand-in for the release server, not
  yet between two published releases.

## Testing for this release

- 43 unit tests on Windows, macOS and Linux (CI).
- 65 scripted end-to-end checks of the real window on Windows 11, including the Avro
  views, read-only documents and the updater (newer release offered, download verified,
  wrong checksum rejected, older release ignored, failed check reported).
- The downloaded-installer step was run for real on Windows 11: the installed copy
  closed, was replaced, and opened again.
