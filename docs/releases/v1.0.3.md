Inkdown 1.0.3 changes one thing: the Android package is now signed with a permanent key.
The application itself is the same as 1.0.2.

`SHA256SUMS.txt` lists the checksum of every file.

## Android: one last uninstall

Versions up to 1.0.2 were each signed with a different throwaway key, so Android refused
to install one over another. From 1.0.3 on every release uses the same key, and later
versions install over this one and keep your documents.

To move to 1.0.3 from an earlier version, uninstall the old app once, then install this
one. Documents kept inside the old app are removed with it: use *Export > Save a Copy to
Downloads* first for anything you want to keep.
