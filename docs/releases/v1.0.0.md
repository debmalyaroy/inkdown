Inkdown 1.0 is the first public release: a native editor for Markdown, code, data and
diagrams, written in pure Rust. It has no web view. The interface, text layout, Markdown,
diagrams and math are all drawn by Inkdown itself, so it starts in under a tenth of a
second and stays small in memory.

## What is in 1.0.0

- **Native interface.** No WebView2, no bundled browser. First frame in 60 to 80 ms and
  74 MB of memory with a text file open. An earlier WebView-based prototype of the same
  editor needed about 2.6 s and 417 MB.
- **Four modes** for Markdown: Read, Write (Word-style editing that saves plain
  Markdown), Split (source and live preview) and Code.
- **Code editor** with multiple cursors, the Sublime Text key map, minimap, folding,
  snippets, completions, bookmarks, macros, build systems, Goto Anything / Symbol /
  Definition, Find in Files with replace, and a two-pane layout.
- **Native rendering** of Mermaid diagrams, Graphviz graphs, charts and LaTeX math.
- **Diagram designer**: draw with blocks and connectors, saved as SVG that reopens for
  editing, with "Copy as Mermaid".
- **Data views**: JSON, YAML and TOML as a tree with validation, formatting and
  conversion; CSV and TSV as tables.
- **Avro**: binary `.avro` data files open read-only as a tree of their schema and
  records (codecs `null`, `deflate` and `snappy`; dates, timestamps and decimals are
  shown readably). `.avsc` schemas are edited as JSON. *Tools: Avro Records to a JSON
  Document* and *Avro Schema to a Document* copy the contents out for editing.
- **Export** to HTML, Word, RTF and PDF, copy as rich text, upload to Google Docs.
- **Nine themes**, session restore including unsaved drafts, AutoSave.
- **Android app** from the same code: all four modes, "Open with Inkdown", saving back
  to the original file, on-screen keyboard.
- **macOS and Linux preview builds.**

## Known limits

- No plugin API or language-server support.
- PDF export needs Edge, Chrome or Chromium installed.
- macOS and Linux builds are compiled and unit-tested by CI but have not been used
  interactively; on macOS, opening a file from Finder does not load it yet.
- The Android build has been tested on an emulator only.
- Google Docs upload needs your own OAuth client ID and has not been tested end to end.
- A file can be open in only one pane at a time.
- Avro: files compressed with `zstandard`, `bzip2` or `xz` are not read; Avro files
  cannot be written; at most 20,000 records are shown.

## Testing for this release

- 40 unit tests on Windows, macOS and Linux (CI), including Avro files written by an
  independent implementation (fastavro).
- 59 scripted end-to-end checks of the real window on Windows 11. The last two fixes
  before release (commands on read-only documents, and the two Avro copy commands) were
  type-checked and unit-tested but not run through this suite.
- Windows installer: silent install, file associations, Start menu entry, uninstall
  entry, launch with a file, and silent uninstall leaving nothing behind.
- Android 15 emulator: launch, all modes, open-with, save write-back, typing.
