Inkdown 1.3.2 adds zoom to every Read view, by gesture, mouse and keyboard, and fixes repeated error messages for a web address that cannot be reached.

| Windows x64, portable | `inkdown-windows-x64.exe` | Stable |

`SHA256SUMS.txt` lists the checksum of every file. Windows 1.0.1 and later update
themselves (*Help > Check for Updates*). The Android package installs over 1.0.3 and later.

## Zoom while reading

Every Read view can now be zoomed, in the same ways on every platform:

- **Pinch** on a phone, tablet or trackpad.
- **Ctrl and the mouse wheel.**
- **Double tap** on a touch screen: larger, and back. In a PDF it zooms in around the
  point that was tapped; with a mouse, a double-click on an empty part of a PDF page
  does the same (on a word it still selects the word).
- **Ctrl+=**, **Ctrl+-** and **Ctrl+0** (also *Larger text* / *Smaller text* in the
  phone's Settings sheet). While reading they zoom what is read; in the editor they
  change the editor's text size as before.

Markdown, AsciiDoc, data trees and tables are laid out again at the new size, so lines
still fit the window instead of running off its side; the place being read stays in
view. Diagrams, pictures and PDF pages zoom as pictures. The range is 50 % to 400 %; a
small label shows the zoom, and a click on it returns to 100 %. The zoom belongs to the
document that is open and is not kept after closing it.

## Fixed

- **A web address that has gone away is reported once.** A tab opened from a web address
  is looked at again every few seconds. When the address could not be reached, Android
  showed the error again at every look, over whatever else was open (a PDF, for
  example), because the system's error text carries a port number that changes each
  time. Now the message appears once, when the trouble starts; the status bar keeps
  showing *cannot refresh*; and the message returns only if the address worked again in
  between.
- **An unreachable address is asked less and less often**: the wait doubles after each
  failure in a row, up to two minutes, and goes back to normal as soon as it answers.
- The message on Android is a plain sentence instead of the system's exception text.

To get rid of such a tab, close it like any other: on a phone, tap the title and then
the × beside the document.

Everything else is as in [1.3.0](v1.3.0.md).

## Testing for this release

- New scripted checks of the real window for zoom by pinch (as the system reports it,
  which is also what Ctrl and the wheel produce) and by keyboard in Markdown, data trees,
  tables and PDF files, and for double-click zoom in a PDF.
- A new unit test for the repeated message and the growing wait; all unit tests on
  Windows, macOS and Linux (CI).
- **Not checked on a touch screen.** The phone was not connected when these changes
  were made: pinch and double tap with real fingers, and the fix for the repeated
  message, still have to be confirmed on a device.
