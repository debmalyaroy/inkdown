Inkdown 1.0.2 fixes the Android app, where most menu items appeared to do nothing, and
adds an Edit menu on every platform.

| Platform | File | Status |
| --- | --- | --- |

`SHA256SUMS.txt` lists the checksum of every file. On Windows, version 1.0.1 offers this
update by itself (*Help > Check for Updates*).

**Android:** this package is signed with a different test key than 1.0.0 and 1.0.1.
Uninstall the old version first; documents saved inside the old app are removed with it,
so copy anything you need out first.

## Android

- **Menus work.** A tapped menu item used to wait until the next touch before it did
  anything, which made most of the menu look dead.
- **Theme follows the system.** The app now reads Android's light or dark setting and
  switches with it.
- **Scrolling.** A finger drag always scrolls, even when it starts on text; a tap places
  the caret; the code editor keeps moving after a flick. Views no longer stop until the
  next touch.
- **Open and Save As use the system file pickers**, so files anywhere on the phone or in
  a cloud drive can be opened and saved. *Open with Inkdown* now also works while Inkdown
  is already running.
- **Print or Save as PDF** through Android's print dialog.
- **Clipboard.** Cut, Copy and Paste use the system clipboard, so text moves between
  Inkdown and other apps.
- **Exports reach other apps.** HTML, Word, RTF and image exports are saved to
  `Downloads/Inkdown`, and *Export > Save a Copy to Downloads* does the same for the
  document itself.
- The side drawer stays below the status bar, and the Back button closes drawers,
  pickers and dialogs.

## All platforms

- **Edit menu**: Undo, Redo, Cut, Copy, Paste, Select All, Find, Replace, Find in Files.
- After a dialog or picker closes, typing goes to the document again without a click.
- Menus and the command palette list only the commands that work on the platform.
- *Copy as Rich Text* retries when another program is holding the clipboard.
- *Show in File Manager* and *Copy Path* say so when the document has not been saved yet.

## Known limits

- Android: scrolling smoothness could only be measured on an emulator that was itself
  slow, so it is unverified on real phones. Two-pane layout, build systems, Find in
  Files across folders outside the app, and Google Docs upload are not available.
- Google Docs upload has still not been tested end to end on any platform.
- macOS and Linux builds are compiled and unit-tested by CI but have not been used
  interactively.
- Nothing is code-signed yet.

## Testing for this release

- 43 unit tests on Windows, macOS and Linux (CI).
- 106 scripted end-to-end checks of the real window on Windows 11, 41 of them new:
  every item of the main menu and its submenus, and the toolbar buttons.
- Android 15 emulator: every menu and submenu, system dark mode, drawer, Back button,
  file picker, Save As, opening a file while running, print dialog, clipboard, export
  to Downloads.
